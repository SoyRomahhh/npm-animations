Empieza en dos pasos

Instala el paquete, importa el CSS y aplica una clase a cualquier elemento.

1. Instala e importa

npm install animaciones-web-soyromahhh
@import "animaciones-web-soyromahhh";

2. Personaliza con variables

<div class="anim-bg-gradient">Hola</div>
:root {
  --anim-color: #5b5de6;
  --anim-accent: #ff8866;
  --anim-duration: 1.2s;
  --anim-radius: 18px;
}
